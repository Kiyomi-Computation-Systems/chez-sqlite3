- **S1. The clone lines before the release.** The docs slice writes the install steps before the
  release slice bumps the manifest. A clone line naming `v0.1.0` would then name a tag that
  doesn't exist, on `main`, for days. The records already read 0.0.0 as "no release":
  `test-manifest` holds the manifest's version to CHANGELOG.md's latest release, "or 0.0.0 while
  there is none" (ADR-0007; `tests/test-manifest.sps`, 549 to 553). So the check takes the same
  reading: at 0.0.0 a clone line names no branch, and clones `main`, which is what the docs on
  `main` describe; from 0.1.0 it names the manifest's tag. The release slice then changes the
  manifest, the changelog and the two clone lines together, or fails (pre-work §4, item 1).
- **S2. The site's packages are a list of their own.** `packaging/debian-prereqs.txt` is the one
  list "every job of ci.yml installs from", so that "a list in two places cannot drift" (its
  header). The site needs another toolchain: Ubuntu's Chez, 9.5.8, below the floor, with
  cmark-gfm and xz (chez-curl's site job). Added to the one list, Ubuntu's Chez would be
  installed beside the Chez every other job builds. So `packaging/debian-site-prereqs.txt` is the
  site's one list, read by the `site` job and by `pages.yml`, with the same step form.
- **S3. `check-ci` holds `pages.yml` line for line.** ADR-0005 holds `ci.yml` to one shape, read
  as text, failing closed, and refuses a second workflow, since it "would run jobs this check does
  not read" (`tests/check-ci.sh`, lines 6 and 7). `pages.yml` needs what that shape refuses:
  `needs:`, a job's own `permissions:` and `environment:`, and two actions beside the
  checkout. It has no part that varies by lane, so the strongest hold is the simplest: its lines,
  comments and blank lines aside, equal `check-ci.sh`'s copy (§4.4).
- **S4. The `site` job is a required check.** Every job of `ci.yml` is required by branch
  protection (progress.md, Now), and a job that no PR must pass checks nothing that merges. The
  maintainer adds it as slice 3 merges, as M3 slice 6's swap was made.
- **S5. No page restates a floor.** "No other house document restates a floor" (global
  constraints, Platforms). The pages will name library versions, and a floor among them would go
  stale when it moves. chez-curl's quick start names "the versions README.org's Requirements
  name", by a link. So `check-floors` gains `docs/` and the rest of README.org (ADR-0008,
  amended; §4.1).
- **S6. What a swept comment keeps.** Q7's recommended option was "as chez-curl's PR #56 was", and
  the pre-work tells that sweep as "milestones, slices, research paths and dates gone and a bare
  ADR number kept" (§3). chez-curl's ledger records the maintainer's rule for it: "a bare ADR
  number stays, as a pointer to why, its amendment dates and decision numbers gone"; its diff
  removed 189 lines naming a decision number and added none. So the sweep keeps `ADR-NNNN` and
  drops "decision N", "amended in …" and the rest (§4.7). Measured at `95d0cc1`, in the 150 files
  the sweep reads: 671 comment lines cite an ADR, 276 a decision number, and 220 an amendment.
- **S7. The sweep leaves `tests/fixtures/` alone.** A fixture is a suite's input: test-conventions'
  decoys put "the word foreign-procedure in a comment" (`tests/test-conventions.sps`, line 388),
  so a fixture's comment can be what a row reads. The pre-work's count of 1,048 lines in 94 files
  is the top of `tests/`; `tests/fixtures/` holds one more line.
- **S8. The README's example has no `import`.** A `scheme run` block is evaluated in an

### Q11. The site's home page

The site renders `docs/*.md`. chez-curl's generator, which Q1 copies, writes `docs/README.md` as
the site's home, `index.html`: it is `(site pages)`' first entry, `page-file-name`'s one case,
and the name `(site links)` rewrites to `index` (chez-curl's `site/pages.sls` and
`site/links.sls`). check-site's seventh invariant holds the nav, after the home, to that page's
list of the pages. Every sibling with a site has an index page: `docs/README.md` in chez-curl,
circuit, chez-http-server, chez-libuv and chez-websocket, and `docs/index.md` in chez-cmark-gfm
and chez-httparse. chez-curl's is 90 lines, what it is, "Ideas to keep in mind" and "The pages";
circuit's generator, which chez-curl's copies, has the same rule. Q5's four pages hold no such
page. Rendering README.org as the home isn't an option:
chez-cmark-gfm renders Markdown alone.

Each case it touches, under each option:

- **The site's first page:** A, the quick start; B, what it is, a few ideas, and the four pages.
- **`docs/` on GitHub:** A, a list of four files; B, the index, rendered below the list.
- **Q5's four pages:** A, four files; B, four pages and an index.
- **The lists of the pages:** A, README.org's alone, which check-site holds the nav to; B,
  README.org's and the index's, check-site holding the nav to the index's, and nothing holding
  README.org's order to it.
- **The copied generator:** A changes two rules, the home being `(site pages)`' first entry,
  written as `index.html`, and a link to it rewritten there; B changes what chez-curl changed of
  circuit's, the names, the blob URL and the nav.
- **`test-docs`:** A, unchanged; B, README.org links the index too, as it must every page.
- **The siblings:** A is the one site in the family without an index; B is every other's shape.

The options:

- **A. The quick start is the site's home (recommended).** The four pages stay four; a reader
  lands where they start; README.org's list is the one list of the pages, and check-site's
  seventh invariant reads it, its `file:docs/…` links in order. The generator's two changed rules
  are held by check-site's invariants 1, 2, 3 and 5.
- **B. An index, `docs/README.md`, as chez-curl's:** a fifth file, the site's home and GitHub's
  view of `docs/`, what it is and the pages; the generator's home rule copied as is.

**Recommendation: A.** Q5 chose four pages over a page per topic, and A keeps them four with one
list of them. B's index would restate README.org's Documentation section beside it, two lists in
two files held in different ways. A's cost is two small rules of a copied generator, each held by
the invariants check-site already has.
**Evidence:** chez-curl's `site/pages.sls`, `site/links.sls` and `tests/check-site.sps` (its
seven invariants); circuit's `site/pages.sls`; the siblings' `docs/`, each read on 2026-11-20;
Q5's answer.

**Answered 2026-11-20: "The quick start is home",** A, the recommendation, chosen from a picker

### 4.1 The docs (ADR-0022, decision 2; ADR-0008, amended)

- **The pages,** each Markdown, ELI5, concise (AGENTS.md):
  - `docs/quickstart.md`, "Quick start": from a clone of the tag to a first query, the library
    path, Homebrew's `chez`, a first program, then where to go;
  - `docs/finding-sqlite.md`, "Finding SQLite": the override, discovery's candidates by world,
    the refusals and their reasons, which systems need the override, `DYLD_LIBRARY_PATH` on a
    Mac;
  - `docs/libraries.md`, "What varies by library": each behaviour that differs between the
    libraries the suites ran on (below);
  - `docs/reference.md`, "Reference": every export, held by `test-reference`.

  The names are this plan's; a slice that renames one says why. The quick start is the site's
  home (Q11), and no index page joins them.
- **What varies by library** comes from measurements already made (pre-work §2's last list):
  Apple's `THREADSAFE=2`, its memory count kept off, no extension loading and `defensive` on;
  FTS5 absent from SQLite's default build and present in Guix's, Ubuntu's, Apple's and
  Homebrew's; Ubuntu's library opening every connection with extension loading's C call on; DQS's
  message differing by version; `ENABLE_MEMORY_MANAGEMENT` leaving a statement's out-of-memory's
  transaction open; a build without `nanosleep` waiting whole seconds; the Mac's `.dylib` retry
  and dyld's messages; `DYLD_LIBRARY_PATH`'s redirect. Each fact on the page is one a suite holds
  on a lane, or a Mac run measured, and the docs review names which (pre-work §4, item 8: "a
  summary inherits its sources' overreach").
- **README.org,** thin, in the siblings' order (pre-work §3; chez-curl's README.org): the title;
  the CI badge; one line of what it is; the AI disclosure, as every sibling's README has; a short
  what it is; **Status**, naming the platforms and SQLites the suites ran on and those that
  haven't run (Q6), "The API may change in any release before 1.0", and CHANGELOG.md, naming no
  version (pre-work §4, item 2); **Requirements**, the two floor lines `check-floors` holds, then
  in prose what the suites need beyond them, a C compiler with `sqlite3.h` and `sqlite3ext.h`,
  GNU `timeout`, and Valgrind for `make test-memory`, and that a program needs none of them
  (pre-work §2); **Installing** (§4.2); **A taste,** the one Scheme block; **Documentation,** the
  pages and the site's address; **License.**
- **The README's block is a twin.** A new `test-docs` rule: README.org holds at least one Scheme
  block, and each equals, line for line, the whole of a `scheme run` block of a page under
  `docs/`, its `;; =>` line included. So the README's example runs, through its twin, in every
  `make test`. It holds the body alone (S8). The rule is held on the suite's own texts first, as
  every rule of `test-docs` is.
- **No page restates a floor** (S5). `check-floors` takes `docs` as a fifth argument: no line of
  a file under `docs/`, nor a line of README.org but its Requirements' list lines, holds either
  floor's dotted text, or the SQLite floor's version number or amalgamation number as a whole run
  of digits, by the workflows' boundary. A page names the floor by a link to README.org's
  Requirements; a library's version is named by whose it is, "Ubuntu 24.04's library", where its
  number is a floor's text. CHANGELOG.md isn't read: an entry records what its release needed.
- **The reference's three gaps** (pre-work §9), each closed in the slice:
  - ADR-0014, line 301: a step's out-of-memory can end a transaction too, not only a read's at
    its reset or finalize (reference, 1141 to 1144 and 753 to 756);
  - ADR-0016, line 349: an expiry past the fold's last step finishes the statement, and the
    resume answers the fold, where the reference's "the resumed fold raises a closed condition"
    (595 to 597) reads as if every expiry raises;
  - ADR-0018, line 175: a list that sets `journal-mode` to any value can't open `:memory:`, each
    reading back `memory`, where the reference shows `wal` alone (142 to 143).
- **The three wordings read against the code** (pre-work §9): a failed close at an expiry
  (ADR-0012, 306 to 310, against the reference, 295 to 297); a failed rollback at an expiry
  (ADR-0017, 422, against 808 to 812); `journal_mode = wal` beside a reserved lock (ADR-0018, 71
  and 167, against the table at 204 to 212). The slice runs each case, and fixes the reference
  where it is wrong, or proposes an amendment where the record is.
- **The docs review** reads every page against the code, and plants faults in the pages to ask
  what wrong docs the checks pass, as chez-curl's did, whose review found seven majors that the
  structural checks had passed (pre-work §3). It audits the records' 36 promises to the
  reference again, and the five more the pre-work found beyond them (§9).

### 4.2 Installing, and the clone lines (ADR-0022, decision 3; ADR-0007, amended)

```sh
git clone --branch v0.1.0 https://github.com/Kiyomi-Computation-Systems/chez-sqlite3.git
scheme --libdirs chez-sqlite3/src --program app.sps
```

- **Nothing is built:** the library is its `src`. A program ran against a bare archive's `src`,
  its `vendor/chez-srfi` empty and nothing built, with the override and by discovery (pre-work
  §8). `make dev` is no install step (pre-work, "What the files couldn't settle").
- **The clone check,** in `test-manifest`, replacing the tripwire: every line of README.org, or
  of any file under `docs/`, that holds `git clone` is, after its leading spaces, exactly
  `git clone --branch vX.Y.Z https://github.com/Kiyomi-Computation-Systems/chez-sqlite3.git`, X.Y.Z
  the manifest's version; at 0.0.0 the same line without `--branch vX.Y.Z` (S1). README.org and
  `docs/quickstart.md` hold one each. Held on fixture trees first, as the tripwire's rows are, so a
  check that never fires can't pass the real tree.
- **The quick start says what a reader meets:** Homebrew installs Chez as `chez`; on a Mac,
  Apple's library is found, and Homebrew's is reached by the override alone (ADR-0002); Apple's
  has no extension loading; how to see what was loaded and why one was refused.
