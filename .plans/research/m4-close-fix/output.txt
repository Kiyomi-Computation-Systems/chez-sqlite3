under build/, each set by CHEZ_SQLITE3_LIBRARY and C_INCLUDE_PATH:

  m3-floor           3.45.1, SQLite's defaults, no virtual table module
  m4cf-floor-vtab    3.45.1, and
  m4cf-current-vtab  3.54.1, each built for this fix from its role's archive,
                     whose sqlite3.c has that role's source pin as its SHA3-256
                     (floor 0474604d...0295, current e2b869d3...ee81), by CI's
                     compile line with four options added, so each lists the
                     virtual table modules Ubuntu's 3.45.1, CI's main and
                     memory lanes, lists:
    $CC -shared -fPIC -O2 -DSQLITE_THREADSAFE=1 -DSQLITE_ENABLE_FTS3 \
      -DSQLITE_ENABLE_FTS4 -DSQLITE_ENABLE_FTS5 -DSQLITE_ENABLE_RTREE \
      -Wl,-z,defs -o build/<dir>/lib/libsqlite3.so.0 sqlite3.c -lpthread -lm
