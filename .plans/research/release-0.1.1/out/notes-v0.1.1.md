Examples, and a page that shows them. The library is unchanged from
0.1.0, and so are
[0.1.0's known limitations](https://github.com/Kiyomi-Computation-Systems/chez-sqlite3/blob/v0.1.0/CHANGELOG.md#known-limitations).

### Added

- **Examples:** five programs in `examples/`, each shown in full, with
  what it prints, on [their page](docs/examples.md): basics,
  transactions and errors, prepared statements, a database file with
  its migrations, and SQLite's JSON functions.

### Changed

- **The quick start** says that git may warn, as it clones the tag,
  that the tag "is not a commit!", and that the clone is a detached
  HEAD: both are expected.
