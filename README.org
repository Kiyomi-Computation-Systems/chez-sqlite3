* chez-sqlite3

A Chez Scheme library that binds SQLite through its C interface.

It is in development. You can open a database with its settings, run SQL and
read its rows, run a transaction, and stop a long statement from another
thread. You can also prepare and step statements yourself, bind values and
read columns.

The [[file:docs/reference.md][API reference]] lists every name the library exports.

** Requirements

- Chez Scheme 10.4.0 or later, built with threads
- SQLite 3.45.1 or later
